# 多任务卡片的滚动归属

状态：已采用。

卡片原先固定高度并裁切溢出内容，只有参数和日志各自滚动；结果区增长后挤压编辑器，并把下载区推到裁切范围之外。

卡片采用固定标题、可滚动内容和固定下载底栏。列表提供 CSS size container，卡片按列表可用高度计算，限制在 360–900px；短窗口或多行卡片由列表滚动兜底。内容区是参数、运行操作和结果的共同滚动容器，日志保留独立的高度上限。

StepEditor 的 scrollMode 默认为 internal，只有多任务卡片传 parent；原有单任务和标准模型编辑页保留内部滚动。编辑器状态与输入渲染分别抽取，事件处理逻辑不变。下载组件保持挂载，使当前卡片的目录句柄在再次运行时保留。

size containment 会影响固定定位元素的包含块，因此编辑器对话框和结果预览通过 portal 挂到 document.body，避免被卡片或列表裁切。

验证入口：开发服务器的 /tests/fixtures/card-layout.html，以本地模拟数据检查四种窗口尺寸、六种任务状态、独立滚动、底栏位置、横向溢出和默认编辑器滚动；不使用真实 API Key 或提交任务。

回滚应同时撤回卡片三段布局、列表 size containment 和 parent 模式接入；任务协议与持久化格式不受影响。平台目录选择能力保持既有实现，本次不验证真实文件系统授权和写入。
